# 國樂 Transformer 第一次 Fine-tuning

本次已完成：以 GMD Transformer 基礎模型初始化，使用使用者指定的六份樂譜 token 資料微調全部模型層；不是從頭訓練，也不是 LSTM。

## 結果

| 項目 | 結果 |
| --- | --- |
| 最佳模型 | guoyue_transformer_finetuned_v1.pt |
| 訓練輪數／最佳輪數 | 60／60 |
| 最佳 validation loss | 0.406496 |
| 重載模型再計算 validation loss | 0.406496 |
| 訓練前擴充 GMD 模型的 validation loss | 5.537029 |
| 獨立 test loss | 未設置；本次只有作品層級的驗證集 |
| GPU | RTX 4060 Ti，BF16 |
| 正式訓練與驗證時間 | 約 21.7 秒 |
| 模型 | 4 層、256 維、8 heads、上下文 512，3,393,224 參數 |
| 學習率 | 最高 0.00003；warmup 20 updates 後 cosine 衰減 |
| Batch／更新數 | 8／1,320 updates |

這是資料很少的第一次概念驗證。改善同時包含對新版 token 語法與新增分類的學習，不能據此證明 GMD 遷移優勢；也不能和舊 GMD 的 0.6928 loss 直接比較。欄位遮罩、詞彙表和資料分布均不同。

## 詞彙表與未知資訊

保留原 GMD 的 133 個 token 與其 ID，再附加 67 個新 token，合計 **200 個**。本次國樂來源自己的 84-token ID 經過對照重編；token 字串與 loss_mask 逐筆比對保持相同。對照在 dataset_manifest.json 的 local_to_unified_id。

國樂保留新版 INST／EVENT／BAR／METER／DURATION 等語法；Transformer 的通用骨幹繼續微調，讓它學習新增語法。小鑼、大鑼、定音鼓等沒有被改成西式 kick／snare。

啟用欄位：樂器、時間、小節／拍號／段落、起音、時值、輪奏、重音、裝飾音、延音線。速度、音高、細部擊法、力度、圓滑線依使用者資料設定維持關閉。

使用 inputs=ids[:-1]、targets=ids[1:]、target_mask=loss_mask[1:]。未知目標不計入交叉熵，右側 padding 也不計入；loss_mask 不作為 attention mask。已測試未知位置的 logits 梯度為零。

## 檔案用途

- `guoyue_transformer_finetuned_v1.pt`：最佳微調模型，已含 200-token 詞彙表、模型設定與國樂分類／欄位設定。
- `last.pt`：最後一輪完整續訓狀態。
- `vocab.json`：此模型專用的 200-token 詞彙表；不要和來源的 84-token ID 混用。
- `summary.json`、`history.json`、`initial_metrics.json`：本次結果、每輪曲線資料、微調前指標。
- `verification.json`：最佳模型重載檢查、各欄位統計、來源／模型雜湊。
- `dataset_manifest.json`：作品切分、ID 對照、欄位設定與來源雜湊。
- `source_vocab.json`、`source_rules.json`、`source_manifest.json`、`source_report.json`：原國樂 token 套件的對照快照。
- `code/`：訓練、準備資料與驗證程式快照。

原始 GMD checkpoint 的 SHA256 仍為 `79adb2def24c518a65a2ce359fe179f55ce46fb1dc0156c2b8177002e29a4690`。已確認其 133 個 ID 保留、48 個 Transformer 骨幹張量實際更新，以及國樂來源四個主要檔案未修改。

目前完成微調與作品驗證。原 `rhythm_transformer.generate` 是 GMD 的 STROKE／VEL 生成器，不適合直接用來展示這個新版國樂 EVENT／INST 模型；下一步要用符合新版語法的生成器，再接國樂音色播放。本次尚未驗證自由生成或真實國樂音色。

若執行中斷，可在專案根目錄使用 `run_guoyue_finetune.ps1 -Resume`；本次已完成 60 輪，原設定續跑不會再新增輪數。若要新增訓練，需明確調整目標輪數並記錄新實驗。

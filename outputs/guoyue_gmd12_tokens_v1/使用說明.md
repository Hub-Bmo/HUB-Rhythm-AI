# 國樂 → GMD 類別新版 TOKEN

這是使用者授權的第二次微調實驗，舊TOKEN未覆寫。

- sequences_all.jsonl：原始132段全部轉換後的token。
- sequences.jsonl：沿用前一輪篩選與切分的130段，供本次訓練。train 100段，validation 30段。
- vocab.json：200項token→ID對照，與前一輪完全相同；資料中的樂器已改用原GMD STROKE ID。
- instrument_mapping.json、樂器對照表.md：32種來源樂器到GMD類別的逐項映射及理由。
- dataset_manifest.json：來源、雜湊、切分、欄位與映射設定。

原始來源全部5316個事件保留，loss_mask與時間／演奏欄位不變。固定詞彙表仍含未使用的舊INST分類，以控制模型尺寸及初始化，不代表本次資料仍使用國樂INST token。腳踩踩鈸沒有來源對應，實際使用11種GMD類別。

新模型與比較報告在 ../guoyue_gmd12_ft_v1/。

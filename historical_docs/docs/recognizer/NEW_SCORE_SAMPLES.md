## 手寫符號的網路查核（2026-10-28）

使用者表示也不知道符號含義，要求搜尋。以下是研究結果，不是已獲使用者確認的作品符號對照，不能直接套入正式音高／技法資料。

- **B、E**：照片中反覆以字母代替音符，與字母音名相符；英式 E=Mi、B=Si，但德式 B 為英式 B♭。此手稿沒有足以確認採用哪種命名、升降與實際八度的圖例，不能由字母直接產生確定 MIDI。來源：[Tunable 自家音名系統說明](https://tunableapp.com/notations/german/)、[Steinberg 官方音名設定說明](https://www.steinberg.help/r/dorico-pro/6.2/en/dorico/topics/user_interface/user_interface_language_instrument_names_changing_t.html)。
- **獨佔小節、斜線兩側各一點的記號**：照片可見兩處與單小節重複記號相符；標準語義是當前小節奏前一小節的內容。此類在程式中應作來源引用／展開，並非略過本小節或回到曲首。來源：[MuseScore 官方手冊](https://musescore.org/en/print/book/export/html/329209?toc=1)。
- **向上波浪箭頭**：上行滑奏是可能解釋，但沒有找到此手稿的圖例或可核對的同版本原譜，不能確認。VSL 確認定音鼓可在單擊餘音或輪奏期間踩踏板滑音；此一般知識不足以證明照片箭頭的確切含義。不可將箭頭直接設成 is_roll=true 或確定 glissando，也不能猜起訖 MIDI。來源：[VSL 定音鼓演奏法](https://www.vsl.co.at/academy/percussion/timpani)。

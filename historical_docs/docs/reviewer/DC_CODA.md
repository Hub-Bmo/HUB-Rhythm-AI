# D.C.／Coda 的核對與試聽

重新啟動「校對與試聽」後，開啟原有校對專案，在「段落與反覆」向下捲動至文字跳轉設定。既有音符、段落、音效與一般反覆資料沿用。

1. 核對範圍需包含開頭、D.C. 與尾奏目的地；本曲可使用 1–200。
2. 保留並核對一般反覆與第一／第二結尾。載入候選可能含不成對記號，須補齊實際原譜上的配對。
3. 選「D.C. 返回後接 Coda」，輸入 D.C. 小節末、回奏至小節末、尾奏起點。
4. 明確選擇「略過一般反覆、採最後結尾」或「重做一般反覆」，再按「加入跳轉草稿」。相同的一組 D.C. 再加入會更新草稿。
5. 按「預覽草稿路線」查看首次、返回後、尾奏三段的完整順序；按「依草稿試聽」比較實際演奏。試聽不會確認路線，也不需呼叫辨識 API。
6. 確定後才勾選「已核對此範圍反覆記號」，按「預覽並確認反覆」。日後正式播放勾選「依確認反覆」，訓練匯出也沿用相同順序。

## 《節慶歡舞》的待核對設定

第 36 頁為紙面 153–156 小節：154 末有 D.C.，155 前有 Coda 圈十字。第 5 頁 17／18 交界另有圈十字。根據符號位置，可先試下面這組草稿：

| 欄位 | 草稿值 |
|---|---|
| D.C. 小節末 | 154 |
| 回奏至小節末 | 17 |
| 尾奏起點 | 155 |
| 返回後一般反覆 | 須以實際演奏核對，程式不預選 |

這表示第一次到 154 末返回 1，回奏至 17 末跳往 155，繼續至曲末。譜面只寫 D.C.，因此這組 Coda 配對仍是待確認解讀；影片 6:28 的音訊對應尚未完成驗證，不能稱為已確認演奏版本。

前次檢查紙面找到的一般反覆如下，不能只靠此次文字跳轉取代：1–8（第一結尾 8、第二結尾 9）、80–84、89–90、137–144。需要保留原有人工決定並對照整頁核對。

若一般反覆以上述四組為準，返回後略過反覆、採最後結尾，整體會有 238 個演奏小節；返回後重做反覆則為 246 個。這是路線邏輯的測試案例，不代表已替你確認實際演奏。

## 避免後續辨識漏掉文字跳轉

程式 A 新增「整頁參考」按鈕：在送出前，將同頁完整譜面作為第二張參考圖，以便檢查裁圖上方、下方及其他樂器附近的 D.C.／Coda、調號、速度。第一張打擊樂器裁圖仍是唯一音符來源。增加參考圖片會增加該次請求的圖片用量；不會自動送出，也不會重跑既有 47 頁。

已辨識的本曲可以在 B 手動補上跳轉，毋須只為這個記號重新辨識整份樂譜。此版尚未支援 D.S.、Fine 或多組文字返回。

## 將 153–154 與返回後內容合成同一個段落

本次已由使用者確認：第二遍跳過第 8 小節。重新啟動 B，進入「段落與反覆」，按「新增跳轉段落…」，填名稱，並直接貼上：

```text
153-154 → 1-8 → 1-7 → 9-17
```

按「預覽完整順序」或「試聽這個順序」，應為 26 個演奏小節、19 個紙面小節。勾選「已核對這個演奏順序」後按「保存為一個段落」。之後選取這一列即可整段試聽或修改，不必拆成四個訓練段落。

這是該段指定的完整順序，第一／第二結尾已直接寫入。若全曲 D.C. 返回後也要先奏一次 1–8，再奏 1–7、9–17，全曲跳轉的「返回後」應選「重做一般反覆」；自訂段落不會自動修改全曲設定。

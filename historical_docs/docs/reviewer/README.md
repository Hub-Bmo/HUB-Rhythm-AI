# MusicAI 校對與試聽（程式 B，第一版）

雙擊根目錄的 **啟動校對與試聽.bat**。這是獨立的本機程式，用於對照原譜、修正辨識、選擇音效、試聽及切分訓練段落。

若 `projects/` 內只有一份校對專案，啟動時會自動開啟；多份作品可用「開啟校對專案」選擇。

## 開始使用

1. 按「匯入辨識資料」，選第一個程式專案內的 `recognition-package.json`，或 A 匯出的 `.recognition.zip`。
2. 程式在 `MusicAI/projects/曲名.score-review/` 自動建立校對資料夾，複製原圖並讀入完成結果。另一首樂譜會建立另一份校對專案。
3. A 還在辨識也可以先匯入，未完成／失敗的小節保留狀態。按「匯入後續結果」讀取後來完成的頁面；相同辨識回應的人工修改與接受狀態保留。
4. 下次按「開啟校對專案」，選 `review-project.json`。搬移時請複製**整個 `.score-review` 資料夾**，其中包含原圖與自訂音效。

所有人工決定保存在 B。B 以唯讀方式讀取 A 的檔案，不會將正在跑的辨識標成中斷，也不會呼叫辨識 API。

若在 A 將已有結果的範圍拆成逐小節重做，請保存並重開 B 再匯入後續結果。舊範圍的事件與人工修改會封存，新小節作為待核對候選接替，不會與舊 OMR 重複。段落定義保留，受影響範圍的反覆確認需重新核對。

若小節編號與照片頁序相反，需要同步整理 A/B 的編號與來源索引，不能只改清單排序。成對改號會保留原始辨識中的舊號碼作為歷史證據；「恢復原始辨識」會保留改號後的小節位置，避免事件又被搬回舊號。完成修復後重新開啟原校對專案即可，不必重新辨識或建立新的校對專案。

## 匯出 Excel 或 CSV 檢查與統計

按上方「匯出 Excel／CSV…」，選 `.xlsx` 活頁簿，或 `.zip` CSV 表格壓縮包。CSV 包解壓後每表一檔，使用 UTF-8 BOM，Excel 可直接讀取中文。這兩種格式與 JSON 使用相同的核對及段落門檻，不另外送出辨識。

若輸出提醒延音線缺少起點、重複起點或尚未閉合，訊息會列出樂器與第幾拍。請核對延音兩端是否對應同一樂器、擊法及音高，並確認起點／延續／終點相接。輪奏波浪線本身不等於同音延音線，放響但未接到下一音的弧線也不能一律當作延音起點。節奏優先模式可保留未知音高與遮罩，但不會因為試聽都使用同一提示音，就將已辨出的不同音高當成同音。

六張表格分別是：

- **段落統計**：原譜／演奏小節數、擊打事件數、確認新起音、起音待確認及全段確認無聲。
- **原譜事件**：每個事件只列一次，列出樂器、拍點、時值、音高、演奏記號、所屬段落與來源。
- **演奏事件**：依每個段落的反覆或自訂順序重列，可統計實際演奏序列中的事件數。
- **休止紀錄**：與敲擊分開；無法定位的休止不擅自補拍點。
- **演奏順序**：每列一個演奏小節，包含無聲小節，可檢查反覆、跳轉與小節重用。
- **欄位說明**：單位、未知值與計數方式。

拍點從 1 起，時值單位是四分音符；數值欄可統計，精確分數欄可查三連音等。輪奏及和弦各算一筆事件，延音延續不算新敲擊，起音未知另列。未知不會變成「否」或零。同小節若在不同段落重用，原譜表只出現一次，演奏表會按段重列。

表格是匯出時的快照，修改 Excel／CSV 不會回寫校對專案，也不會更動 JSON。正式訓練仍保留 JSON 及其 training_mask；目前不提供從 Excel 匯入修改。

## 少打字的核對方式

節奏格的每個聲部名稱下方都有樂器下拉選單及「套用」按鈕。可直接選擇既有樂器，也可先輸入「堂鼓」「鑼」等文字再展開選單篩選；最近套用的樂器會排在前面。按「套用」後立即保存，右側校對欄、事件清單和本譜音色清單同步更新。

格子上方的「套用範圍」預設是「本小節這一列」，也可選「本頁同名聲部」或「整份譜同名聲部」。跨小節只按原譜聲部名稱完全相同的資料套用，不按「第幾列」推測，也不會建立後續匯入的自動改名規則；會換樂器的聲部宜按小節處理，個別音符仍可用右側欄位修改。

整列套用會包含該列的休止，但略過已刪除資料；原始辨識、原譜聲部、拍點、時值、音高與演奏標記保留。既有擊法能在目標樂器找到同名擊法時會沿用，找不到則保留未對應，不擅自改成一般敲擊。實際修改的項目重新標為待核對；未改變的項目維持原狀。

重新啟動後，在「核對與播放」按「核對助手／批次整理…」（音色頁也有入口）：

助手是可與主視窗交替操作的獨立工具視窗，開著時仍可使用右側事件編輯器的下拉選單。再次按入口會叫回同一個助手，不會重複開啟；在助手切換核對方式或執行整理前，會先保存主視窗正在編輯的有效修改。若在主視窗修改資料後直接按助手的批次接受，會先更新檢查並要求重新勾選核對確認。

1. 核對方式選「節奏優先（未知細節可保留）」。技法、實際音高、重音、裝飾音及未判定的延音可保留未知，不必硬猜；樂器、敲擊起點與時值仍需明確。
2. 名稱錯誤只修一次：原名稱選「軍鼓」，改為「軍鈸」，按「整譜套用」。這也會修正共用列中的軍鼓字樣，原 AI 回應仍保留；之後新增辨識結果沿用這個專案的規則。
3. 按「依名稱整理樂器」，一次建立小堂鼓、鈴鼓等單一明確名稱的身分；原本泛稱鼓／鈸的音色對應可整理為該原譜名稱。已選的技法／樣本保留，沒有資料的技法不會自動填成一般敲擊。共用聲部及描述性暫名不猜測。
   若已確定尚未對應的擊法都可使用基本擊法，可按「全部套用基本擊法」，一次把整譜已確認樂器、尚未對應擊法的敲擊事件設成「一般敲擊」。已設定的擊法、輪奏、重音、裝飾音、原辨識與人工備註保留；休止、已排除及樂器未對應的資料略過。套用後仍為待核對，其他問題不會自動通過；之後新匯入的資料需要時可再按一次。
4. 範圍可選「已建立段落」「全譜」「目前小節」。核對節奏後勾選下方確認，按「接受可用資料」；有實質問題的項目留在清單，不會讓整批接受失敗。雙擊問題小節可回原譜。

「節奏優先」接受的是可用的節奏資料，未知欄位不代表「沒有」。匯出 JSON 每筆事件帶 training_mask，之後的訓練器必須略過 mask=false 的標註；未知延音造成是否重新敲擊不明時，attack=null，不能當成確定的新敲擊或休止。現有訓練器尚未接上這個新版資料格式。

仍可切回「完整標註」要求實際音高、技法與演奏記號齊全。已知延音接錯、時間不明、樂器不明、來源辨識失敗或段落順序未確認仍需處理，不會自動填值掩蓋。

## 建議先用一頁練習

### 1. 填入共通資訊

填「共通拍號」及「四分音符／分鐘」，按「保存共通設定」。例如這份《節慶歡舞》第一頁印有 `4/4`、`♩=144`。

共通設定作為沒有記錄的小節的補充；小節本身已記錄的拍號／速度優先。可按原譜旁「本小節設定」修正單一小節。

有音高的樂器若只有簡譜數字，還需要「簡譜 1 的實際音高」，**必須含八度**。例如 `G2` 表示 MIDI 43，`G3` 表示 MIDI 55；不能只因譜上寫 `1=G` 就猜八度。填好並保存後，按「依基準換算待填音高」。缺少音級或八度的事件仍保留未知。

### 2. 確認樂器與擊法

「樂器與音效」預設開啟「本譜樂器音色」：只列出這份譜辨識到、尚未排除的樂器／共用聲部，每行直接選預設音色並按「試聽」。選完自動保存，重新開啟與匯入後續結果都會保留；休止列也列出，同名但不同逗號、斜線或換行的名稱合併顯示。沒有出現在譜中的預設樂器不會佔一行。

例如軍鈸可選「鈸」、小堂鼓可選「鼓」。這裡只改試聽音色，不會把原譜樂器改名、抹掉音高或把音符自動標為已核對。選「沿用原有設定」可恢復原本音色／自訂 WAV；選內建音色則暫時優先使用所選音色，原採樣檔仍保留。

需要修正樂器身分、新技法或匯入 WAV 時，再開「進階：樂器名稱、擊法與自訂音效」：

1. 選既有樂器；或在名稱欄填新名稱、選音效及是否需要音高，再按「新增樂器」。
2. 選擊法，必要時按「新增擊法」。音級與輪奏分開保存，不把數字 1、2、3 當成不同擊法。
3. 下方選「原譜名稱」，按「對應到上方選取的樂器與擊法」。例如原辨識若誤寫軍鼓，可依你核對的原譜對應到軍鈸。
4. 「只限原符號」留白會套用同名的全部待核對項目；有填文字時只套用與該原始符號完全相同的項目。已接受事件不會被批次重配。

名稱、樂器與技法使用穩定編號。原始辨識名稱與符號另存，修正後仍可查閱。

### 3. 聽與修正

- 左側選紙面小節，原譜橘框是目前小節、綠框是選取事件。按「整頁原譜」可查看頁首與其他聲部；Ctrl＋滾輪縮放。
- 節奏格的橘色是候選、綠色已接受、灰色休止，依原譜聲部排成一列；同列切換不同樂器不再拆成多列。未知起點放在該列的「待定位（非拍點）」卡片，可直接點選，原譜會顯示該筆定位。
- 預設不會因雙擊空白而新增音符。需要時按「補入敲擊」，或先勾選「啟用雙擊補音」才在格內補入十六分音符；起點、時值仍可修改。
- 單筆可點待定位卡片的 ×，或選取後按「刪除選取」；格內／事件清單取得焦點時也可按 Delete。刪除不需先通過欄位驗證；被刪資料的未完成草稿不用補完。
- 按「刪除整列／樂器…」可選只刪目前小節的原譜聲部，或刪整份譜中該正式名稱的已匯入資料；視窗先顯示筆數與涵蓋小節。刪除是排除試聽／訓練，不刪原始辨識。
- 誤刪可按「復原上次刪除」，整批恢復為待核對；也能在「事件與休止清單」勾「顯示已刪除」，再「還原選取刪除」。還原保留原本的修正值與備註，不會改回 AI 原始答案。
- 「事件與休止清單」包含全休止與未讀清楚位置；按 Ctrl 選多筆可以一起接受／排除。
- 右欄可修正樂器、擊法、第幾拍、時值、實際音高、輪奏、重音、裝飾音、延音線、連奏與力度。時間以四分音符為 1，支援 `1/2`、`1/3` 等分數。
- 音高欄的 `?` 保留原始待確認音高；清空表示這筆事件沒有音高。和弦用逗號分隔，例如 `G2,B2`。
- 有效修改在切換事件／小節與關閉時保存；無效欄位會提醒修正，不會悄悄丟棄。修改後重新成為待核對，可用「恢復原始辨識」還原。
- 按「聽這小節」或輸入起訖小節播放範圍。「只聽樂器」可逐軌檢查。播放時可跟隨小節與紅色游標，或取消跟隨自行瀏覽；編輯事件會停止當前試聽。
- 接受時若有缺值，訊息會指出小節、樂器、符號與缺少的欄位，並自動選到第一筆有問題的事件。不是目前畫面選中的事件一定有錯；重複休止可到「事件與休止清單」逐筆選取修正。
- 預設勾選「含待核對試聽」。取消後只聽已接受事件；兩者都不會改變訓練資料。
- 未知位置、缺少音高、缺少樂器對應等會顯示在「試聽問題」。起點／時值未知的音略過試聽並列出原因。
- 預設勾選「未知實際音高時，以 1=C3 試聽相對音高」。例如簡譜 1、5 可先聽出高低差；這個 C3 是試聽基準，不是認定原譜實際音高。原資料中的 MIDI 保留未知；完整標註模式要求填妥，節奏優先模式可保留並以遮罩排除該音高標註。音級或相對八度讀不清時，仍用提示音。關閉此選項即恢復未知音高的提示音。
- 已對應樂器但未確認擊法時，先用該樂器的一般校對音效，並列出提醒；核對與匯出的門檻不變。輪奏用較短的連續音效，避免長尾蓋住下一顆音。
- 看過原譜與辨識疑問後，勾選「已核對原譜與疑問」，再「接受選取」或「接受本小節」。不需要的候選可刪除／排除；整小節休止仍需接受其休止證據。

節奏優先下，個別休止的未知位置／時值可以只保留來源，不再強制猜值。這種休止匯出為 timing_known=false、interval 遮罩為 false，不當成已知時間的休止訓練答案。真正敲擊的未知起點仍會阻擋；無效數字或超出小節的值也不會因此放行。

## 音效

內建鼓、定音鼓、鈸、大鑼、小鑼、鈴／鐘及提示音是合成校對音色，不是真實演奏採樣。

每種擊法可以匯入自己的 **16-bit PCM WAV、單／雙聲道、15 秒以內**音效；檔案複製進校對專案。這類單次樣本按原音播放，不依 MIDI 自動改調；檢查實際音高時請使用內建有音高音色。可另外匯出試聽 WAV。

輪奏在試聽中暫以每秒 20 次快速敲擊呈現。資料仍是一筆有時值的輪奏事件，不能把試聽敲擊頻率當成譜面指定速度。裝飾音使用簡化前倚音試聽；力度與重音影響音量。相接的同音延音線合併起音，連奏文字保留供核對。

## 段落與反覆

- 在「段落與反覆」填段落名稱、紙面起訖小節，加入或修改段落。段落可以跨頁；此版段落不能彼此重疊。
- 段落清單新增「擊打事件數」「資料狀態」。計入反覆／自訂順序中的事件引用，輪奏／同時和弦仍是一筆，已知延音接續不算新敲擊；未確認反覆先按紙面範圍估計並標明。0 若伴隨缺資料／待核對，不能直接當作全段無聲；「全段已核對休止」才表示來源休止證據已核對。
- 可以選無需訓練的段落，按「移除選取段落」；訓練 JSON 不再包含該段。其他保留段落若引用同一紙面小節，仍保留該小節的事件。這不會刪除原圖或辨識紀錄。
- 若一段跨返回或尾奏，按「新增跳轉段落…」，填名稱與實際演奏範圍，例如 `153-154 → 1-8 → 1-7 → 9-17`。預覽或試聽後，勾選「已核對這個演奏順序」並保存為一個段落。此例共 26 個演奏小節，第二遍跳過 8；範圍本身已是演奏順序，不另套全曲反覆。跳轉段落可以引用先前段落的紙面小節，一般範圍段落彼此仍不得重疊。
- 選取跳轉段落後，按「聽選取段落」即按該順序播放；按「修改選取跳轉段落…」可修改，修改順序後需重新核對。這是段落自己的演奏順序，不會改寫整首的 D.C.／Coda 設定。
- 先填「反覆核對範圍」，例如小節 1 至 9，再按「載入此範圍候選」。檢查配對，並補入模型漏掉的起點。候選只是草稿。
- 反覆起點／終點使用小節號；第一／第二結尾使用起訖與第幾次演奏。修改後必須重新預覽確認，草稿可跨重開保存。
- 勾選「已核對此範圍反覆記號」再按「預覽並確認反覆」。沒有反覆也須清空該範圍清單並確認。範圍須涵蓋完整反覆與所有結尾，不能截斷在第一結尾。其他尚未核對的小節保留待確認，播放／匯出不能把它們當成無反覆。
- 本曲範例：起點 1、終點 8、總共 2 次、第一結尾 8（第 1 次）、第二結尾 9（第 2 次），會顯示 `1–8 → 1–7 → 9`。
- 這份譜的上述四筆記號已有辨識候選，選範圍 1–9 載入即可，不必重打。之後回「核對與播放」把播放範圍設為 1–9，勾選「依確認反覆」。
- 另支援一組 D.C. 返回開頭，或 D.C. 返回後接 Coda。填明返回位置、回奏終點、尾奏起點，以及返回後是否重做一般反覆；先「預覽草稿路線」或「依草稿試聽」，確定後再確認。詳細步驟及本曲待核對設定見 [D.C.／Coda 操作說明](DC_CODA.md)。D.S.、Fine、多組文字返回仍未支援，原候選保留且阻擋訓練匯出。

## 匯出

「匯出已核對段落」產生新版 `musicai-reviewed-training` JSON，**只包含已建立段落的紙面小節**，並列出段落外未匯出的小節。輪奏、修飾、實際音高、來源及反覆順序皆保留；休止提供證據但不產生敲擊。

段落內仍有未核對、未知起點／時值、樂器不明、辨識失敗或沒有休止證據時，整次匯出會列原因並停止。完整標註另外要求音高、擊法及演奏記號完整；節奏優先則保存未知與遮罩。不能將全部排除當成已核對全休止。

這是新版中間資料，尚未直接接上模型訓練器或舊版的 CSV／token 化流程。格式與驗證範圍見 [DATA_CONTRACT.md](DATA_CONTRACT.md)。
